# 校服方案展示页设计文档

日期: 2026-09-12
项目: mypandora
路由: `/uniform`

## 背景与目标

原「石家庄市中小学校服方案展示」网站(`http://sjzjyj2027.k3scc.top`)为临时上线,随时可能关闭。
为保证日后仍可方便查看,需先将全部校服图片下载保底,并在 mypandora 项目中重新实现一个展示页。

原始数据已探明:

- 3 个类别:小学(A)、初中(B)、高中(中职)(C),每类 15 个方案编号(1~15),共 45 个方案
- 每方案 4 张图,共 180 张 webp,尺寸 1920×1358(约 3:2),每张约 120KB,总计约 20MB
- 图片托管于腾讯云 COS,公开可直接下载
- 原站无学校名称,方案仅有编号,本实现沿用编号展示

## 用户决策(已确认)

| 决策点   | 选择                                                                 |
| -------- | -------------------------------------------------------------------- |
| 浏览方式 | 列表(网格)+ 点击打开大图(灯箱)                                       |
| 页面位置 | mypandora 新增路由 `/uniform`                                        |
| 图片存放 | 已上传至 CDN `https://img.mypandora.cn/`,运行时直连 CDN,不随仓库打包 |
| 方案标识 | 只用编号,沿用原站风格                                                |
| 实现方案 | 方案 A:单页 + Tab + 网格 + 灯箱,零运行时请求                         |

## 架构

- 路由:`src/routes/uniform/+page.svelte`(单页,客户端可交互,adapter-static 预渲染)
- 数据:`src/lib/data/uniforms.js` 构建期静态导出三个类别的方案列表,无运行时 fetch
- 图片:CDN `https://img.mypandora.cn/{primary|junior|senior}/{A1..C15}/1..4.webp`(运行时直连,首屏已 `preconnect`;`static/` 内不再存放校服图,仓库体积约减 24MB)
- 方案编码:小学=A、初中=B、高中=C,编号 1~15

## 页面结构与交互(移动优先)

- 顶部标题「石家庄市中小学校服方案展示」+ 说明文字
- 三个 Tab:小学 / 初中 / 高中(中职),切换过滤网格;**Tab 栏 sticky 吸顶 + 半透明毛玻璃背景**,滚动时随时可切学段
- 网格 **移动优先**:手机 2 列大卡片 → `sm` 3 列 / `lg` 4 列 / `xl` 5 列;卡片为第 1 张封面图 + 标签「编号 A1」,封面懒加载
- 图片 alt 文本格式:`{类别}编号{code}`,例「小学编号A1」
- 点击卡片打开灯箱(全屏遮罩),展示该方案 4 张大图:
  - 画廊基于 **Swiper**(`swiper` 核心 + Pagination 模块):手机触摸左右滑动切图,圆点指示器,桌面保留左右箭头
  - 键盘 ← → 切图、ESC 关闭
  - 「上一套 / 下一套」在同一类别内跳转,跨套时回到第 1 张(`{#key school.code}` 重挂画廊)
  - 点击背景关闭;打开时锁定 body 滚动
- 底部弱化展示归属说明隐藏相关链接(随原站结构,仅保留展示目的)
- 底部弱化展示归属说明

## 视觉风格

- 沿用 mypandora 现有 Tailwind + 暗色模式(mode-watcher)
- 主题色沿用原站蓝色系(#1558a6)

## 边界与错误处理

- 封面图 `loading="lazy"`,180 张不影响首屏
- 路由元信息设置 `title` / `description`
- 图片缺失时浏览器按常规显示占位(不额外处理,数据已全量校验存在)

1. 已按 `{category}/{code}/{n}.webp` 从 COS 全量下载 180 张并校验(180 files,每张非空)

- 不做学校名称对照
